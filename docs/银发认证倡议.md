# 银发认证 · 一个提议

> **未成年人有防沉迷，老年人也该有银发认证。**

银发认证不是一个机构、不发证书、不收费。
它是一个公开的概念，一句话就能说清：

> **银发认证，认证的是一台手机——就像手机号码要完成实名认证一样。**
> **设备完成认证后，这台手机上的所有 App、所有网页，一律禁止出现任何广告。**

不是让老人一个一个去关广告，
而是整台设备、一次认证、终身清净。

我们希望有一天，"银发认证"像"无糖标识""绿灯食品"一样，
成为人人看得懂的标签：看到 🛡，就知道这款应用对老人是干净的。

## 为什么是这个概念

**老人的注意力，不该是别人的生意。**
广告是把注意力打包卖给第三方。年轻人被明码标价，老人被变本加厉——
他们更难分辨真假、更难关掉弹窗、更承受不起点错一下的代价。

**买不起广告的东西，不代表该被广告围猎。**
老人的钱要买菜、看病、交话费、给孙辈买零食，消费需求清清楚楚。
对老人狂轰滥炸，商业上近乎无效，却实实在在造出了三样东西：
手机卡顿、上当受骗、不敢碰手机。既然无利可图，何必为难他们？

**认证不是表扬，是底线。**
通过认证不代表优秀，只代表"没把老人当猎物"——
就像食品配料表，干净是本分，不是恩赐。

## 我们呼吁每款应用做到的三件事

1. **对老人不投广告**：主流广告联盟都支持按人群定向关闭——把 55 岁以上的用户关掉，技术上一行配置的事。
2. **不耍假"×"，不吓唬人**：关闭按钮就得能关；"您的手机已中毒"这类文案零容忍。
3. **大字、少步骤、不设坑**：正文字号大一点，核心路径短一点，付费前多问一句。

## 怎么参与

- **转发这句话**：「未成年人有防沉迷，老年人也该有银发认证。」——发到家庭群，就是参与。
- **用脚投票**：给爸妈换上无广告的桌面，只留干净的应用；见到广告套路，随手举报。
- **点亮提议**：到 [GitHub 仓库](https://github.com/safphere/leling-launcher) 点一颗 Star，让提议被更多人看到。
- **开发者**：如果你愿意，把上面三件事做进你的应用，然后坦然挂上 🛡。
